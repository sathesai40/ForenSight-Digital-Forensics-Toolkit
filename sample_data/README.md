# ForenSight Sample Data

These files are synthetic demonstration data, not acquired forensic evidence:

- `sample_evidence.bin`: plain-text payload explicitly marked synthetic.
- `raw_logs/sample_auth.log.example`: fictional authentication events using documentation IP addresses.

The `.log.example` suffix allows this reviewed example to be published while raw `.log` files remain ignored. No hash baseline directory is currently supplied. Never commit real evidence, credentials, investigation records, or generated reports.
